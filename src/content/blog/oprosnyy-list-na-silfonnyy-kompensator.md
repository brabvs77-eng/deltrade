Заявка на компенсатор чаще всего приходит строкой «компенсатор сильфонный DN 100 — 6 шт.». Поставщик отправляет в ответ опросный лист производителя на полторы страницы, и заявка останавливается: часть полей снабжение заполнить не может, а обращаться к проектировщику за каждой строкой по отдельности — это ещё несколько дней переписки.

Разберём опросный лист по полям: что означает каждое, откуда берётся значение и какие поля нельзя заполнять предположительно. В конце — форма, которую можно отправить ответственному специалисту одним письмом.

## Ситуация: компенсатор подбирается по перемещениям, а не по диаметру

Сильфонный компенсатор — не переходник по диаметру, а изделие, рассчитанное на определённое перемещение при определённых давлении и температуре, с ограниченным числом циклов. Два компенсатора одного DN могут различаться компенсирующей способностью в несколько раз, а также типом — осевой, сдвиговый, угловой, универсальный.

Значения перемещений — результат расчёта участка трубопровода: они зависят от длины участка, температурного перепада, схемы неподвижных опор и направляющих. Ни поставщик, ни снабжение эти величины не определяют. Именно поэтому опросный лист заполняется совместно с тем, кто отвечает за проектное решение.

Общие технические требования к сильфонным компенсаторам и компенсационным устройствам задаёт **ГОСТ 32935-2014**. Он определяет, что должно быть указано и подтверждено, но не заменяет каталог: компенсирующая способность, допустимое число циклов и материалы указываются производителем для конкретной серии.

## Разбор полей опросного листа

| Поле | Откуда берётся значение | Что даёт поставщику |
| --- | --- | --- |
| Рабочая среда | Раздел проекта по системе | Определяет применимость материалов сильфона и патрубков |
| Рабочее давление | Проект, рабочие параметры участка | Отбор серии по PN |
| Пробное давление | Проект, программа испытаний | Проверка допустимости испытательного давления для изделия |
| Рабочая температура | Проект, режим работы системы | Ограничения серии по температуре, влияет на ресурс |
| Тип компенсатора | Проект (осевой / сдвиговый / угловой / универсальный) | Вид воспринимаемых перемещений |
| Компенсирующая способность, осевая | Расчёт участка | Основной параметр подбора |
| Компенсирующая способность, боковая | Расчёт участка | Для сдвиговых и универсальных исполнений |
| Компенсирующая способность, угловая | Расчёт участка | Для угловых и универсальных исполнений |
| DN, мм | Спецификация, чертёж узла | Размер присоединения |
| Тип присоединения | Чертёж узла (под приварку / фланцевое) | Определяет исполнение патрубков или фланцев |
| Строительная длина | Чертёж узла, ограничения по месту | Проверка вписываемости в участок |
| Наличие кожуха | Проект, условия участка | Защита сильфона |
| Направляющий патрубок | Проект, направление потока | Влияет на монтажную ориентацию изделия |
| Стяжки | Проект, условия монтажа и транспортировки | Фиксация изделия до установки |
| Материал сильфона | Проект, требования по среде | Согласуется с проектным решением |
| Материал патрубков и фланцев | Проект, спецификация | Совместимость с трубной частью |
| Количество циклов | Расчёт режима работы участка | Ресурс изделия при заданном перемещении |
| Количество, шт. | Спецификация | Объём поставки |
| Дата потребности | График монтажа | Планирование поставки |

Значения из этой таблицы — то, что берётся из проекта. Ответ производителя по конкретной серии — обозначение изделия, паспортная компенсирующая способность, масса, габариты и допустимое число циклов — приходит уже после заполнения.

> **Что уточнить.** Компенсирующую способность, число циклов, пробное давление и тип компенсатора запрашивайте у проектировщика или ответственного специалиста. Эти поля нельзя заполнить по аналогии с прошлым объектом: они следуют из расчёта конкретного участка. Незаполненное поле, отмеченное как требующее уточнения, безопаснее подставленного наугад значения.

## Какие поля вызывают больше всего вопросов

### Тип компенсатора

Осевой воспринимает перемещение вдоль оси, сдвиговый — поперечное, угловой — поворот, универсальный — комбинацию. Тип связан со схемой участка: расположением неподвижных опор и направляющих. Если в проекте тип не назван прямо, в опросном листе указывают ожидаемые перемещения по каждому направлению и оставляют тип на согласование.

### Давление: рабочее и пробное

Рабочее давление отбирает серию. Пробное — величина, при которой участок испытывают; она может превышать рабочее, и допустимость такого давления для конкретного изделия проверяется по документации производителя. Указывать нужно оба значения, иначе несоответствие вскрывается на этапе испытаний, когда компенсатор уже вварен.

### Комплектация: кожух, направляющий патрубок, стяжки

Эти позиции задаются проектом и условиями участка. Направляющий патрубок связан с направлением потока — значит, у изделия появляется монтажная ориентация, и её нужно передать монтажникам. Стяжки удерживают изделие в транспортном положении: их снимают по инструкции производителя, а не заранее. Наличие кожуха влияет и на габарит, и на возможность нанесения изоляции по участку.

### Материалы

Материал сильфона и материал патрубков — два разных поля. Патрубки должны быть совместимы с трубной частью по свариваемости и по исполнению фланцев (для фланцевого присоединения — по **ГОСТ 33259-2015**). Отличия по присоединению подробно разобраны в статье про [компенсаторы под приварку и фланцевые](/blog/silfonnye-kompensatory-privarka-flancevye/).

## Типовые ошибки при заполнении

- **Заполнены только DN и количество.** Такой опросный лист не считается: без перемещений, давления и температуры серия не определяется.
- **Компенсирующая способность взята «с запасом» на глаз.** Завышение перемещения меняет и серию, и цену, и иногда строительную длину. Значение берётся из расчёта.
- **Не указано пробное давление.** Изделие подобрано по рабочему давлению, а испытания участка проводят на большем — и требуется пересогласование.
- **Пропущено число циклов.** Для участков с частыми пусками и остановами ресурс становится определяющим параметром, а не второстепенным.
- **Не оговорена монтажная ориентация.** Если в комплекте направляющий патрубок, изделие устанавливают по направлению потока; без пометки это выясняется после монтажа.
- **Присоединение указано словом «фланцевое» без исполнения.** Уплотнительная поверхность ответного фланца проверяется отдельно — как и для остальной арматуры, см. материал про [ответные фланцы, крепёж и прокладки](/blog/otvetnye-flancy-krepyozh-prokladki/).

## Памятка: форма опросного листа

Отправьте эту форму ответственному специалисту одним письмом — так все открытые поля закрываются за один цикл, а не за пять.

```
Объект / участок: 
Позиция спецификации №: 
Количество, шт.: 
Дата потребности на объекте: 

РАБОЧИЕ ПАРАМЕТРЫ (из проекта)
  Рабочая среда: 
  Рабочее давление, МПа: 
  Пробное давление, МПа: 
  Рабочая температура, °C (мин / макс): 
  Расчётное количество циклов: 

ПЕРЕМЕЩЕНИЯ (из расчёта участка)
  Тип компенсатора (осевой / сдвиговый / угловой / универсальный): 
  Осевое перемещение, мм (сжатие / растяжение): 
  Боковое перемещение, мм: 
  Угловое перемещение, град.: 

РАЗМЕРЫ И ПРИСОЕДИНЕНИЕ
  DN, мм: 
  Тип присоединения (под приварку / фланцевое): 
  Для приварки: наружный диаметр и стенка патрубка, мм: 
  Для фланцев: PN, исполнение уплотнительной поверхности (ГОСТ 33259-2015): 
  Строительная длина, мм (требуемая / ограничение по месту): 

КОМПЛЕКТАЦИЯ
  Кожух (да / нет): 
  Направляющий патрубок (да / нет): 
  Стяжки (да / нет): 
  Ответные фланцы, крепёж, прокладки (входят / нет): 

МАТЕРИАЛЫ
  Материал сильфона: 
  Материал патрубков / фланцев: 

ДОКУМЕНТЫ
  Паспорт, сертификаты — перечень: 
  Стандарт (ГОСТ 32935-2014 / иные требования проекта): 

Поля, требующие уточнения (указать, у кого запрошено): 
```

Форма построена так, что видно ответственного за каждый блок: рабочие параметры и перемещения закрывает проектировщик, размеры и присоединение — чертёж узла, комплектацию — проект вместе с монтажниками. Если изделие подбирается на замену уже установленному, набор исходных данных другой — он разобран в статье про [замену сильфонного компенсатора](/blog/zamena-silfonnogo-kompensatora/).
