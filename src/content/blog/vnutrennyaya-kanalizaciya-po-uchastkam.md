На объекте четыре корпуса, в каждом по девять этажей, монтаж внутренней канализации идёт захватками. В снабжение приходит одна ведомость на весь объект: трубы по диаметрам, фасонные части, хомуты, крепления — всё общей суммой. Материал приезжает одной поставкой, складируется где получится, и через две недели никто не может ответить на простой вопрос: хватит ли отводов на третий корпус.

Дальше обычный сценарий: в одном месте отводы лежат без дела, в другом их нет, часть позиций «ушла» без следа, а докупать приходится срочно. Разберём, как разложить поставку внутренней канализации по участкам так, чтобы выдача материала была управляемой.

## Ситуация: одна ведомость на объект — это не план поставки

Проектная ведомость отвечает на вопрос «сколько всего нужно». Она не отвечает на вопросы, которые задаёт объект: что нужно на этой неделе, в каком корпусе, кому выдать и что осталось с прошлой партии.

Между этими двумя документами и происходят потери. Материал, привезённый одной партией на весь объект, живёт в общем котле: бригада берёт то, что ближе, учёт по участкам не ведётся, а дефицит обнаруживается в момент, когда до него уже нельзя подготовиться.

Особенность канализационных систем усугубляет картину. Это многопозиционная поставка с большим числом мелких изделий: фасонные части, хомуты, крепления, ревизии. Их легко пересчитать в накладной и невозможно контролировать «на глаз» на этаже. Состав такой поставки подробно разобран в материале про [комплектацию канализации SML](/blog/komplektaciya-kanalizacii-sml/).

## Как разложить ведомость по участкам

Деление придумывает не снабжение и не поставщик: границы участков задаёт тот, кто отвечает за производство работ. Задача снабжения — перенести эти границы в ведомость поставки без искажений.

| Что определяем | Кто даёт данные | Зачем это в ведомости |
| --- | --- | --- |
| Признак деления (корпус, секция, этаж, захватка, стояк) | Производитель работ | Партия должна совпадать с фронтом работ, а не с видом товара |
| Перечень участков и их коды | График производства работ | Код участка становится основой маркировки партии |
| Состав по каждому участку | Проектная ведомость, узловые схемы | Позволяет отгружать комплект, а не набор позиций |
| Дата потребности по участку | График монтажа | Определяет очередность партий |
| Место выдачи и приёмки | Организация работ на объекте | Влияет на разгрузку, подъём и хранение |
| Ответственный за приёмку партии | Производитель работ | Без фамилии приёмка превращается в формальность |
| Остаток с предыдущих партий | Фактический пересчёт на объекте | Корректирует объём следующей партии |

> **Важно.** Разбивка на партии — организационное решение по объекту, а не изменение проекта. Состав и характеристики позиций берутся из проектной ведомости без корректировок; меняется только то, как материал распределён во времени и по участкам.

## Маркировка партий: минимум, который работает

Маркировка полезна ровно настолько, насколько она совпадает с тем, как объект устроен в реальности. Избыточная система кодов не приживается, отсутствие кодов приводит к общему котлу.

Рабочий минимум — три уровня:

1. **Код участка.** Например, «К2-С1-Э05» (корпус 2, секция 1, этаж 5) или номер захватки по графику.
2. **Номер партии.** Порядковый, с датой потребности. Одна партия — одна поставка на один участок.
3. **Ссылка на строку ведомости.** Позволяет при приёмке сверять не «примерно то», а конкретную позицию.

Этот код должен присутствовать в трёх местах: в заявке поставщику, в отгрузочных документах и на упаковке. Если он есть только в заявке, на объекте маркировки не будет.

### Что даёт совпадение партии с захваткой

- Приёмка проверяет комплект, а не абстрактное количество: видно, чего не хватает для конкретного участка.
- Недостачу обнаруживают до выхода бригады, а не в день монтажа.
- Остатки привязаны к участку, и их можно пересчитать.
- Претензии по недостаче или повреждению оформляются по конкретной партии, а не «по объекту в целом».

## Контроль остатков и перераспределение

Остатки есть всегда: запас на резку, непредвиденные узлы, изменения по месту. Проблема начинается, когда их никто не считает.

Практика, которая работает без сложных систем учёта: перед формированием каждой следующей партии ответственный за участок даёт фактический остаток по ключевым позициям — хомутам, отводам каждого угла, креплениям. Не расчётный, а пересчитанный. Этот остаток вычитается из следующей заявки.

Второе правило — перераспределение между участками фиксируется письменно. Если с одного корпуса на другой ушли сорок хомутов, в ведомости обоих участков должна появиться запись. Иначе через месяц один участок числится укомплектованным, а фактически пуст.

Общие принципы построения графика партий и оформления изменений разобраны в статье про [поэтапную поставку на объект](/blog/poetapnaya-postavka-na-obekt/); здесь важна привязка партии именно к монтажному участку.

## Типовые ошибки

- **Партии формируются по видам товара.** «Сначала все трубы, потом все фасонные части» — удобно для отгрузки и бесполезно для монтажа: участок не закрывается.
- **Маркировка есть только в заявке.** Если код не попал в накладную и на упаковку, на объекте партия обезличивается.
- **Приёмку никто не подписывает персонально.** Без ответственного за участок недостача не фиксируется вовремя.
- **Остатки не пересчитываются.** Следующая партия считается «по проекту», и объект копит излишки по одним позициям при дефиците по другим.
- **Перераспределение между участками не фиксируется.** Ведомости перестают отражать реальность, и ошибка накапливается.
- **Мелочь не разложена по участкам.** Хомуты, крепёж, заглушки часто отгружают «общим мешком» — именно они потом и заканчиваются первыми.

## Памятка: ведомость поставки по участкам

```
Объект:
Признак деления (корпус / секция / этаж / захватка):
Общая ведомость (реквизиты документа):

ПАРТИЯ №___
  Код участка:
  Дата потребности на объекте:
  Место разгрузки, этаж, способ подъёма:
  Ответственный за приёмку (Ф. И. О., телефон):

  Состав партии (по строкам общей ведомости)
    № строки | Позиция | Ед. | Кол-во по проекту | Остаток на участке | К поставке
    ---------|---------|-----|-------------------|--------------------|-----------
             |         |     |                   |                    |

  Мелкие позиции, упакованные отдельно (хомуты, крепёж, заглушки):
  Маркировка на упаковке (код участка + № партии):
  Документы к партии:

КОНТРОЛЬ
  Дата пересчёта остатков:
  Перераспределение между участками (откуда / куда / что / кол-во):
  Позиции с риском дефицита:
  Позиции, требующие уточнения:
```

Колонка «остаток на участке» — самая полезная и самая часто пропускаемая. Если её заполнять на каждой партии, объект перестаёт заказывать то, что у него уже лежит.
